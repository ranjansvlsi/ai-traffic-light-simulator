# AI Traffic-Light Simulator

A laptop-only traffic-light simulation built with Python, Tkinter, and scikit-learn.

The Decision Tree model chooses which direction gets a green light based on simulated vehicle queues. The model uses generated sample data.

## Important
This is an educational software simulation. It is not connected to real traffic lights and has not been tested with real traffic data.

## Requirements
Python 3 and scikit-learn

## Run on Windows
Install the required library:
python -m pip install -r requirements.txt

Start the simulator:
python traffic_ai.py
